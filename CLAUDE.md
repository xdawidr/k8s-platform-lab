# Project context

Personal portfolio project. I'm Dawid — IT sysadmin (1+ year, banking),
moving into DevOps. Building a Kubernetes platform from scratch to close
my real gap: no commercial cloud or IaC experience.

Target stack: GKE, Terraform, Helm, GitHub Actions, Prometheus/Grafana,
PostgreSQL on a RHEL-family VM.

## How to work with me

- Do NOT write Terraform, Kubernetes manifests, or Helm charts for me.
  I write those myself — that's the entire point of this project.
- When I'm stuck: explain the mechanism and ask guiding questions.
  Do not hand me a working solution.
- Code review: list problems and questions. Don't apply fixes.
- You may write: README, helper scripts, linter config, commit messages.
- Push back on my architecture decisions — ask "why this way".
- Be direct. I'd rather hear something is weak than get praise.

## Conventions

- Everything in this repo is in English.
- Conventional commits (feat/fix/docs/chore/refactor).
- Scripts in Bash, not Python — I'm deliberately rebuilding Bash skills.
- Read PROGRESS.md at session start for current status.
- Never commit secrets, real hostnames, IPs, or anything from my employer.
